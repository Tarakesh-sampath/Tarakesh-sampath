ML engineer. Right now I work on LLM training efficiency — layer-importance profiling, block expansion, continued pretraining and instruction tuning of open models (Gemma family), multi-GPU training with FSDP, and serving with vLLM on Blackwell hardware. Most of that lives in private repos.
